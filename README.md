# Website kecil untuk pasangan ♡

## Isi folder
- `index.html` — struktur halaman
- `style.css` — desain, warna, animasi, dan responsif
- `script.js` — keypad 6 digit dan tombol musik
- `assets/foto-kita.jpg` — foto yang diberikan
- `assets/perfect.mp3` — tempat file musik

## Sebelum dipublikasikan
1. Masukkan file audio MP3 yang kamu miliki/berhak gunakan ke folder `assets`.
2. Namai file tersebut **`perfect.mp3`**.
3. Jangan ubah nama file foto kecuali ikut mengubah alamatnya di `index.html`.

Musik tidak disertakan karena hak cipta. Website hanya memanggil file `assets/perfect.mp3` yang kamu tambahkan sendiri. Browser biasanya memerlukan tombol klik sebelum audio bisa diputar.

## Kode halaman
Kode akses enam digit: `010824`.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini (bukan hanya file ZIP).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
6. Tunggu proses selesai; alamat website akan muncul di bagian Pages.

Untuk mengubah tulisan, edit bagian pesan di `index.html`. Untuk mengganti foto, ganti `assets/foto-kita.jpg` dengan foto lain dan pertahankan nama file yang sama.
